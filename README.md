# Welcome to Randomize!

Can't decide between a few options? With this app, you can choose at random.

---

# Requirements

- Flutter SDK

---

# Start the App with flutter command

```bash
flutter run
```

---

# Build the App for Android

```bash
flutter build apk
```

You can find the file in './build/app/outputs/apk/release/'.

# Build the App for Linux

```bash
flutter build linux
```

You can find the file in './build/linux/x64/release/bundle/'.

# Build the App for Windows

```bash
flutter build windows
```

You can find the file in './build/windows/x64/runner/Release/'.

---

# Privacy Notice

This app runs only locally on your device and doesn't send anything anywhere.
